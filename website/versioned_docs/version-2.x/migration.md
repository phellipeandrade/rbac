# Upgrade from 2.x to 3.x

**RBAC 2.x is deprecated.** Refer to the maintained [3.x documentation](/rbac/docs/intro/).

Follow the [complete 2.x → 3.x migration guide](/rbac/docs/migration-2-to-3/) before upgrading the dependency. Pay special attention to the Node.js minimum version, package export paths, legacy `when` callbacks, schemas and database adapters.

If you still need the legacy API, consult the [2.2.3 snapshot](./api.md). The latest published 2.x npm version is 2.2.3.
