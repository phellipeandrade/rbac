# Migração da 1.x

**A linha 1.x foi descontinuada.** A documentação mantida é a da [3.x (latest)](/rbac/pt-BR/docs/intro/).

Para atualizar uma aplicação legada, siga os guias nesta ordem:

1. [Migrar da 1.x para a 2.x](/rbac/pt-BR/docs/migration-1-to-2/) — declarações TypeScript, novas APIs e integrações.
2. [Migrar da 2.x para a 3.x](/rbac/pt-BR/docs/migration-2-to-3/) — Node.js, exports, callbacks condicionais e adapters.

Se a aplicação precisar permanecer temporariamente na 1.x, fixe a versão e teste todas as decisões de autorização. Consulte a [referência histórica](./api.md).
