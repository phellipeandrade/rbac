# Migrar da 2.x para a 3.x

**O RBAC 2.x foi descontinuado.** Consulte a documentação mantida da [3.x](/rbac/pt-BR/docs/intro/).

Siga o [guia completo de migração 2.x → 3.x](/rbac/pt-BR/docs/migration-2-to-3/) antes de atualizar a dependência. Revise especialmente a versão mínima do Node.js, os subcaminhos de exports, os callbacks `when`, os schemas e os adapters de banco de dados.

Se ainda precisar da API anterior, consulte a [referência da 2.2.3](./api.md). A última versão publicada da linha 2.x é a 2.2.3.
